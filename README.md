# Line_follower_webots### Days 6–7: Sensor-Based Robot Control

**Objective:** Connect infrared sensor readings to wheel motor control in Webots.

**Implemented:**
- Read values from two infrared sensors.
- Compare sensor readings using `if` and `elif` conditions.
- Set wheel velocities based on sensor readings.
- Practise forward and reverse wheel motion to produce turns.

**Learning outcomes:** Python conditionals, sensor feedback, motor velocity control, and simulation loops.

**Next step:** Calibrate sensor readings and verify reliable line detection and tracking.
